# About this machine

`dreamstation.systems` is a single‐CPU virtual server running **Debian 13
(trixie)**. It is a personal machine, not a business, and it has no uptime
guarantee beyond the operator’s attention span — which is, in fairness, quite
long.

## Why it exists

Because the protocols that predate the web are still standardised, still
implemented, still perfectly good, and almost nobody runs them any more. This
box runs them. Some of them are one‐line RFCs from 1983 that exist to echo your
bytes back at you, and it runs those too.

The busiest thing on it by a wide margin is **NTP**. It is a member of
`pool.ntp.org`, which means a continuous trickle of time requests from devices
whose owners will never know this machine exists. That is the best kind of
public service.

## Why it looks like this

Ubuntu 8.04 LTS shipped in April 2008 with a brown desktop, a Human icon theme,
and Firefox 3. It was the first Linux release that a lot of people — including
this machine’s operator — actually installed on purpose and kept.

This site is a recreation of that desktop, rebuilt from a 1280x720 screenshot
with a measuring tape. It is not a screenshot itself: the panel, the window
frame, the title bar gradient, the toolbars and the masthead are HTML and CSS,
and the numbers came out of ImageMagick one pixel row at a time. The
[Colophon]({{ROOT}}/colophon) has the details, including the ones that
turned out to be surprising.
